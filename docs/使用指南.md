# 使用指南

本文说明 Token 用量页面的每一项功能怎么用。安装与配置见 [README](../README.md)。

---

## 1. 打开页面

安装后侧边栏会出现「Token 用量」入口。点开是完整页面；侧边栏里同时有一个精简面板，显示今日总量和当前范围。

页面从上到下依次是：范围选择 → 指标卡片 → 趋势 → 排行 → 请求记录。

---

## 2. 选择时间范围

顶部一排按钮：

| 按钮 | 覆盖区间 |
|---|---|
| 今日 | 本地今天 00:00 到现在 |
| 本周 | 本周一 00:00 到现在 |
| 本月 | 本月 1 日 00:00 到现在 |
| 本年 | 本年 1 月 1 日 00:00 到现在 |
| 全部 | 从第一条记录到现在 |
| 自定义 | 你指定的起止日期 |

全部按**本地日历**计算，不是「最近 24 小时」这种滚动窗口。

### 自定义范围

1. 点「自定义」，两个日期框会预填当前显示的范围
2. 点日期框任意位置展开日历
3. 选开始日期，再点另一个日期框选结束日期
4. 点「应用」刷新统计

要点：

- **只有点「应用」才会刷新**，中途改日期不会影响已应用的统计
- 结束日期包含当天完整数据
- 开始日期不能晚于结束日期：选开始日期时，晚于结束日期的日子是灰的；选结束日期时同理
- 日历右侧「快速选择」可以直接跳到任意年份和月份，不用逐月翻页
- 也可以直接在框里键入 `2026-09-06` 或 `2026/09/06`，回车生效

最后一次选择会被记住，下次打开还是这个范围。

---

## 3. 看指标卡片

七张卡片：

| 卡片 | 含义 |
|---|---|
| 总计 | 输入 + 输出 + 缓存读 + 缓存写 |
| 输入 | 未命中缓存的提示词 Token |
| 输出 | 模型生成的 Token（含推理） |
| 缓存 | 缓存读取 + 缓存写入 |
| 缓存命中率 | 缓存读取 ÷（缓存读取 + 未命中输入） |
| 推理 | 推理 Token，是输出的一部分 |
| 请求数 | 该范围内的模型步骤数 |

**缓存命中率是按 Token 加权的**，不是把每次请求的命中率取平均。Provider 没有上报缓存计数时显示 `—`，不会显示成 0%。

---

## 4. 趋势图

### 柱状图

- 悬停任意柱子，弹出该周期的明细：总计、输入、输出、缓存、缓存命中率、请求数
- 气泡会自动避开鼠标位置，不会挡住正在看的柱子
- 右上角切换粒度

### 粒度规则

粒度随范围自动调整，只显示该范围支持的那几个：

| 范围 | 可选粒度 |
|---|---|
| 今日 | 按小时 |
| 本周 | 按日 |
| 本月 | 按日、按周 |
| 本年 | 按日、按周、按月 |
| 全部 | 按周、按月、按年 |
| 自定义 | 按跨度自动决定（1 天内按小时/日，3 天内按日，70 天内按日/周，800 天内按周/月，更长按月/年） |

切换范围时，如果当前粒度仍然可用就保留，否则回落到该范围的默认粒度。

### 年度热力图

「本年 + 按日」会切换成热力图：12 行（月）× 31 列（日）。

- 颜色越深表示当天用量越大，分四档
- 灰色表示当天没有用量
- 空心框表示还没到的日期
- 今天用一个小圆点标记，不会和选中状态混淆

---

## 5. 排行

- 右上角在「模型 / Provider」之间切换
- 按总量降序，每行显示名称、所属 Provider 和总量
- 点任意一行，会把它设为当前筛选条件

「未识别」这一行默认隐藏，可在「设置」里打开。

---

## 6. 请求记录

- 按时间倒序，每页 50 条
- 列：时间、Provider、模型、输入、输出、总 Token
- 底部「加载更多」翻页
- Provider 没有返回 usage 的请求显示「未知」，不会被当成 0

只记录真正产生了消息的请求；没有返回任何消息的步骤默认不显示在记录里（但仍计入请求数）。

---

## 7. 筛选

点右上角「全部模型 ▾」展开一棵树：

```
Provider
└─ 账号
   └─ 套餐
      └─ 模型
```

- 点任意层级即可按它筛选
- 顶部搜索框可以搜模型 id 或自定义名称
- 「清除筛选」回到全部
- 按钮上会显示当前筛选条件

没有信息量的层级不会画出来：比如账号名和 Provider 名重复时（常见的一路由一账号），账号层会被跳过。

---

## 8. 重命名与套餐标签

在筛选树里，Provider、账号、模型行右侧有编辑按钮：

- **重命名**：设置显示名，只影响展示
- **设置套餐**：给模型打一个套餐标签，可用于筛选

**真实 id 永远保留**，鼠标悬停可以看到，清空显示名就会恢复成原始 id。重命名不会改动任何历史数据或 Token 数字。

---

## 9. 数字格式

右上角「数字格式」：

- **简写**：`4.25B`、`385.03M`、`191.68K`
- **完整**：`4,254,321,987`

作用于页面上所有数字，选择会被记住。

---

## 10. 设置

右上角「设置」菜单：

| 选项 | 作用 |
|---|---|
| 显示未识别排行项 | 在排行里显示「未识别」这一行 |
| 显示未返回 usage 提示 | 当有请求没有 usage 时，在页面上显示提示条 |

两个选项都会持久化。

---

## 11. 常见疑问

**为什么总计和 Provider 后台对不上？**

以 Provider 上报的 `usage` 为准。不同 Provider 对「输入」的定义不同，插件统一换算成 `总计 = 输入 + 输出 + 缓存读 + 缓存写`。

**为什么有些请求是「未知」？**

Provider 没有返回 usage 字段。这类请求计入请求数，但不计入 Token 合计。

**为什么热力图有些格子是空心的？**

那是还没到的日期。

**数据存在哪？**

`$DSH_HOME/token-usage/usage.db`，详见 [隐私与数据说明](隐私与数据说明.md)。
